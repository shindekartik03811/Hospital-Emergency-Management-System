# Hospital Emergency Management System

## 📌 Project Description
The Hospital Emergency Management System is a software application designed to manage patient registration, emergency cases, and treatment priorities efficiently. It uses a **Priority Queue** to prioritize emergency patients and a **Linked List** to maintain patient records dynamically.

The system helps hospital staff manage patients systematically and ensures that patients with higher emergency priority are attended to first.

## 🎯 Objectives
- To manage patient registration and records.
- To assign priorities based on the patient's emergency level.
- To treat emergency patients before normal patients.
- To maintain patient information using a linked list.
- To track treatment completion and update patient records.
- To demonstrate the practical use of data structures in healthcare management.
